# Nerdio

> Nerdio automates Microsoft cloud desktop environments (Azure Virtual Desktop, Windows 365, Intune) for IT departments and Managed Service Providers. Nerdio Manager for Enterprise reduces Azure compute costs by 50-70% and automates AVD and W365 deployment for IT teams; Nerdio Manager for MSP provides multi-tenant desktop management for MSPs serving hundreds of clients. Founded 2017, backed by General Atlantic and Lead Edge Capital at a $1.2 billion valuation.

## Products
- [Nerdio Manager for Enterprise](https://getnerdio.com/nerdio-manager/enterprise/): Cloud desktop management for IT departments; automates AVD provisioning, image management, and Azure cost optimization.
- [Nerdio Manager for MSP](https://getnerdio.com/nerdio-manager/msp/): Multi-tenant platform for MSPs; manage hundreds of client environments from a single console.
- [Nerdio for Windows 365](https://getnerdio.com/nerdio-windows-365/): Automates Windows 365 Cloud PC provisioning, management, and cost control at scale.

## Microsoft Technology Solutions
- [Azure Virtual Desktop (AVD)](https://getnerdio.com/solutions/nerdio-for-avd/): Nerdio's AVD management layer; automates provisioning, host pool scaling, image management, and cost controls.
- [Microsoft Intune](https://getnerdio.com/solutions/nerdio-for-intune/): Intune policy deployment and endpoint management automation for enterprises and MSPs.
- [Microsoft 365](https://getnerdio.com/solutions/nerdio-for-microsoft-365-management/): M365 tenant management and deployment automation via Nerdio's unified platform.
- [Windows 365](https://getnerdio.com/nerdio-windows-365/): Cloud PC lifecycle management; provisioning, scaling, and cost governance for W365 environments.
- [Azure Local](https://getnerdio.com/solutions/nerdio-for-azure-local/): On-premises Azure Stack HCI management for hybrid cloud desktop deployments.
- [FSLogix](https://getnerdio.com/solutions/nerdio-for-fslogix/): Profile container management and optimization via FSLogix integration.
